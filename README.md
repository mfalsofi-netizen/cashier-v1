# كاشير-V1 (Cashier-V1)

تطبيق ويب متكامل لإدارة الطلبات وفواتير الكاشير، مصمم للعمل دون اتصال دائم بالإنترنت عبر التخزين المحلي (`localStorage`)، وجاهز للنشر على **GitHub Pages** أو تحويله إلى تطبيق أندرويد **APK** عبر حاوية `WebView`.

**تطوير:** مناف جلال

## أبرز المميزات
- **واجهة متجاوبة وهوية بصرية ثابتة:** باللون الأزرق الملكي (`#0652a5`) وخطوط `Cairo` و`Tajawal` مع شاشة ترحيب (Splash Screen).
- **دعم متعدد العملات:** `SAR`، `YER`، و`USD`.
- **تحقق متسلسل عند حفظ الطلب:** التحقق من اسم الصنف، الكمية، سعر التكلفة، سعر البيع، تكلفة الشحن الفعلي، والشحن على العميل مع تركيز تلقائي على الحقل غير الصحيح.
- **سجل الطلبات والديون وكشف الحساب الموحّد:** عرض المبالغ المتبقية حسب العملة، وتجميع فواتير العميل الواحد مع تسديد الدفعات من الأقدم للأحدث (FIFO).
- **تقارير الأرباح والسيولة:** فصل **الربح المحصَّل فعلياً** عن **الربح المعلَّق (آجل)** مع عرض **إجمالي المتبقي عند العملاء** و**إجمالي الربح الدفتري** وإمكانية التصفية والتسديد المباشر.
- **الفاتورة الحرارية والمشاركة:** معاينة الفاتورة، طباعتها، تصديرها كصورة `JPG` مع نافذة معاينة للحفظ المباشر أو المشاركة في بيئات `WebView / APK`، وإرسال الملخص عبر واتساب.
- **النسخ الاحتياطي والاستعادة:** تصدير واستعادة ملف `JSON` أو نسخ/لصق النص مباشرة.

## النشر على GitHub Pages
1. ارفع محتويات الحزمة (`index.html` و`manifest.json` و`README.md`) إلى مستودع GitHub.
2. من **Settings > Pages** اختر **Deploy from a branch** وحدد فرع `main` والمجلد `/ (root)`.
3. افتح الرابط المباشر لتشغيل التطبيق أو تمريره إلى أداة بناء ملف **APK** مع تفعيل `DOM Storage` وتنزيل الملفات والروابط الخارجية.
